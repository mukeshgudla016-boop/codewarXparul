# 🚀 AI Project Mentor

AI Project Mentor is a full-stack, responsive web application designed for final-year college engineering students to discover personalized software project ideas, generate comprehensive technical blueprints, track interactive development roadmaps, and chat 24/7 with an AI mentor for viva presentation guidance.

---

## ✨ Features

- **Personalized AI Matching**: Generates 3-5 high-impact project ideas tailored to your academic branch, skills, available duration, and difficulty preference.
- **Detailed System Blueprints**: Includes problem statements, objectives, functional requirements, database schemas, API specs, and visual architecture flow diagrams.
- **Interactive Milestone Roadmap**: Phase-by-phase timeline with task completion checkboxes, setup code snippets, and progress percentage tracking.
- **24/7 AI Mentor Chatbot**: Stateful AI mentor providing context-aware answers to code debugging, database choices, deployment, and external examiner viva questions.
- **Dual AI Engine & Demo Mode**: Seamlessly supports Google Gemini API, OpenAI API, and a built-in Offline Demo Mode.
- **Blueprint Export**: Download complete project blueprints as structured `.md` report files.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, Modern ES6 Modules, Custom CSS3 Design Tokens (Dark Theme, Glassmorphism, Responsive Grid)
- **Backend / Dev Server**: Python HTTP Server
- **AI Services**: Google Gemini API, OpenAI API, Offline Heuristic Engine
